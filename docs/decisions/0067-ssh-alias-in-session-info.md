# 0067 - 다른 컴퓨터 세션의 세션 정보에 ssh 별칭을 보인다

Date: 2026-10-14
Status: Accepted. ADR 0011(peers)의 목록 항목 모양에 `ssh` 필드 하나를 더한다. ADR 0060과 같은 원칙으로, 이 컴퓨터가 아는 정보는 이 컴퓨터가 계산한다.

## Context

1. **세션 정보의 "기기"는 `book` 같은 peer 이름만 보인다.** 그 컴퓨터에 들어가 에이전트를 직접 보려면 어떤 `ssh` 명령을 쳐야 하는지는 따로 기억해야 했다.
2. **peer 이름과 ssh 별칭은 서로 무관하다.** peer 이름은 `--peer 이름=URL`로 붙이는 라벨이고, 별칭은 이 컴퓨터의 `~/.ssh/config`의 `Host`다. 같은 컴퓨터를 가리켜도 이름이 다를 수 있고, 주소 표기도 다를 수 있다. peer URL은 MagicDNS 짧은 이름(`mac-book`)인데 ssh 설정의 HostName은 전체 이름(`mac-book.<tailnet>.ts.net`)이거나 IP인 경우가 있다.
3. **그쪽 서버는 이 컴퓨터의 ssh 설정을 모른다.** 별칭은 사용자가 지금 앉은 컴퓨터에서만 의미가 있다.

## Decision

1. **`app/ssh-aliases.mjs`가 `~/.ssh/config`에서 구체적인 `Host` 별칭을 모은다.** `Include`를 따라간다(`~`, `~/.ssh` 기준 상대 경로, 마지막 경로 조각의 `*`·`?` glob, 깊이 5). `*`, `?`, `!`가 든 패턴, 공백이나 쉼표가 든 이름, `-`로 시작하는 이름은 건너뛰고 `Match` 블록은 해석하지 않는다. 설정 파일은 읽기만 하고 고치지 않는다.
2. **각 별칭의 실제 HostName은 `ssh -G <별칭>`으로 푼다.** 연결하지 않고 설정만 계산하는 명령이다. 별칭마다 병렬로 2초 제한이고, ssh가 없거나 실패하면 그 별칭은 빠진다. 사용자 이름, 포트, 키 경로는 출력에서 HostName만 읽고 버린다.
3. **peer와 별칭을 맞추는 규칙.** peer URL의 호스트가 별칭의 HostName과 같으면 맞다. 아니면 `dns.lookup(all)`로 푼 주소가 겹치면 맞다(IP는 그대로 쓴다). loopback 주소(`localhost`, `127.*`, `::1`)는 맞추지 않는다. 여러 별칭이 맞으면 peer 이름과 같은 별칭, 그 다음은 가장 짧은 별칭, 그래도 같으면 사전순이다.
4. **결과는 10분 캐시하고 실패도 캐시한다.** `ssh -G` 결과(별칭 목록)와 peer별 결과가 각각 캐시다. 세션 목록은 별칭 풀이를 최대 1초만 기다린다. 더 걸리면 그 목록에는 `ssh`를 붙이지 않고, 풀이는 뒤에서 계속되어 다음 목록부터 붙는다. 목록 요청이 DNS나 ssh 때문에 막히지 않는다. fs, exec, lookup, 시계는 주입할 수 있다.
5. **`peerProvider(name, base, { fetch, ssh })`가 목록 항목에 `ssh: "<별칭>"`을 붙인다.** 별칭이 없으면 필드가 없다. 그쪽 서버가 보낸 `ssh` 값은 믿지 않고 항상 버린 뒤 이 컴퓨터에서 계산한 값만 쓴다. 이 컴퓨터의 세션에는 `ssh`가 없다. 별칭 이름만 싣고 어떤 비밀도 싣지 않는다.
6. **웹 세션 정보에 "SSH 접속" 줄을 더한다.** 값은 `ssh book`처럼 그대로 복사해 쓸 수 있는 명령이다. "기기" 줄은 그대로 peer 이름이다. 별칭이 없는 세션에는 줄이 없다.

## Consequences

- 다른 컴퓨터 세션의 정보 창에서 접속 명령을 바로 복사할 수 있다.
- ssh 설정이 없거나 맞는 별칭이 없으면 화면은 예전과 같다.
- 첫 목록 요청은 `ssh -G`를 별칭 수만큼 띄우고(몇십 ms) 최대 1초 기다릴 수 있다. 이후 10분은 프로세스를 띄우지 않는다. 설정을 고치면 최대 10분 뒤나 서버 재시작 뒤에 반영된다.
- `Match` 조건이나 `Host` 아래 조건부 `Include`는 해석하지 않으므로, 그런 블록에서만 정의된 별칭은 보이지 않을 수 있다.
- 영향 범위: `app/ssh-aliases.mjs`(신규), `app/peers.mjs`, `app/server.mjs`, `app/index.html`, `tests/ssh-aliases.test.mjs`(신규), `README.md`, `docs/architecture.md`.
