# 0047 — 웹은 세션 제목 맨 앞의 Nerd Font 아이콘을 빼고 보여 준다

Date: 2026-10-11
Status: Accepted. 사용자 요청.

## Context

omp 18.9는 새 세션 제목을 `아이콘 코드: 제목` 모양으로 만든다(`title.icons`, 기본 `nf+emoji`). 그 컴퓨터의 omp가 Nerd Font 기호 모드(`symbolPreset: nerd`)이면 아이콘으로 이모지 대신 Nerd Font 글자를 제목에 그대로 저장한다. 이 글자는 유니코드 사용자 정의 영역(예: U+F0EC2)에 있어 웹 글꼴로는 그릴 수 없다. 맥북 세션 제목이 웹, PiP, 모바일, macOS 앱에서 빈 네모나 알 수 없는 기호로 보였다. 터미널은 Nerd Font가 있으면 제대로 그린다.

## Decision

1. 웹 화면(같은 `index.html`을 쓰는 PiP, 모바일 PWA, macOS 앱 포함)은 세션 목록을 받을 때 제목 맨 앞의 사용자 정의 영역 글자 하나와 뒤 공백을 뺀다. `RECORD: 제목`처럼 코드부터 보인다.
2. 서버 응답과 세션 파일은 바꾸지 않는다. 터미널 화면은 원래 제목을 그대로 보여 준다.
3. 이모지 아이콘(`🖥️ START:`)은 그대로 둔다. 제목 가운데의 사용자 정의 영역 글자도 건드리지 않는다.

## Consequences

- 맥북처럼 Nerd Font 기호 모드인 컴퓨터의 세션은 웹에서 아이콘 없이 보이고, 이모지 모드 컴퓨터의 세션은 이모지와 함께 보인다.
- Nerd Font 글꼴을 웹에 포함하지 않으므로 설치 파일 크기는 그대로다.
- 영향 범위: `app/index.html`.
