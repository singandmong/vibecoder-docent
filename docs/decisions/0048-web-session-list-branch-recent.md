# 0048 — 웹 세션 목록도 워크트리, 브랜치, 최근 작업을 보여 준다

Date: 2026-10-12
Status: Accepted. 사용자 요청. ADR 0045의 세션 정보를 웹 화면에도 쓴다.

## Context

ADR 0045로 `GET /api/sessions`가 `worktree`, `branch`, `detached`, `recent`를 돌려주고 터미널 세션 선택창이 이를 카드로 보여 준다. 웹 세션 목록(같은 화면을 쓰는 모바일, macOS 앱 포함)은 제목과 저장소, 폴더, 제공자, 컴퓨터, 시각만 보여 줘 같은 저장소의 여러 워크트리 세션을 구별하기 어려웠다.

## Decision

1. 세션 항목은 제목 아래에 최근 작업 한 줄(회색 12px, 한 줄 말줄임)을 둔다. 마우스를 올리면 "최근 작업: …" 전체 문장을 보여 준다.
2. 메타 줄은 저장소, 워크트리(저장소와 같은 보라색), 폴더(저장소나 워크트리와 이름이 다를 때만), 브랜치(초록, 가지 아이콘), 제공자, 컴퓨터, 시각 순서다. 브랜치가 아닌 커밋이면 `abc1234 (브랜치 아님)`.
3. 세션 검색은 제목, 저장소, 폴더, 워크트리, 브랜치, 최근 작업, 작업 경로, 첫 요청, 컴퓨터를 함께 찾는다.
4. 터미널처럼 이모지 아이콘은 쓰지 않는다. 웹의 다른 아이콘처럼 SVG를 쓴다.

## Consequences

- 웹과 터미널이 같은 세션 정보를 보여 준다. 표시 방식만 화면에 맞게 다르다.
- 세션 항목이 한 줄 길어져 한 화면에 보이는 세션 수가 조금 줄어든다.
- 옛 버전 서버(peer)의 세션에는 브랜치와 최근 작업이 없어 그 줄이 빠진다.
- 영향 범위: `app/index.html`.
