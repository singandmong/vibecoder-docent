# 0045 — 세션 선택창은 저장소, 브랜치, 최근 작업을 카드로 보여 준다

Date: 2026-10-11
Status: Accepted. 사용자 요청. ADR 0038의 세션 선택 목록을 넓힌다.

## Context

터미널 세션 선택창(`@` 목록과 첫 화면 목록)은 세션 제목 한 줄과 흐린 폴더 이름, 제공자, 시각만 보여 줬다. 같은 저장소에서 여러 워크트리와 브랜치로 동시에 작업하면 제목만으로는 어느 세션인지 고르기 어려웠다. 사용자는 저장소 이름, 워크트리와 브랜치, 최근 작업 한 문장을 이모지와 색으로 구분해 보여 달라고 했다.

## Decision

1. `GET /api/sessions`는 돌려주는 세션(최근 200개)마다 `branch`, `detached`(브랜치가 아닌 커밋일 때), `worktree`(연결된 워크트리일 때 그 폴더 이름), `recent`를 붙인다. 저장소 위치는 폴더별로 기억하고, 브랜치는 바뀌므로 요청마다 `HEAD`를 읽는다. 브랜치는 세션 당시가 아니라 지금 그 폴더의 브랜치다.
2. `recent`는 모델을 부르지 않고 전사 끝부분에서 고른다. 에이전트의 마지막 답 첫 문장을 쓰고(코드 블록, 표, Markdown 기호 제외), 답 글이 없으면 마지막 사용자 요청을 쓴다. 꼬리 256KB에서 못 찾으면 2MB까지 한 번 더 읽는다. 파일이 바뀌었을 때만 다시 읽는다.
3. 다른 컴퓨터(peer) 세션은 그쪽 서버가 붙인 값을 그대로 쓴다. 그쪽 서버가 옛 버전이면 카드에 브랜치와 최근 작업이 빠진다.
4. 터미널은 세션마다 세 줄 카드를 그린다. 첫 줄은 `📦 저장소`(강조색), `🌿 브랜치`(초록), `🌳 워크트리`(금색), 지금 세션 `✓`, 흐린 `제공자 • 컴퓨터 • 상대 시각`. git 밖이면 `📁 폴더`. 둘째 줄은 세션 제목, 셋째 줄은 흐린 `🕘 최근 작업`. `DOCENT_SYMBOLS=ascii`와 `TERM=dumb`은 ASCII 아이콘(`[R]`, `br:`, `wt:`, `>`)을 쓴다.
5. `@` 목록 검색은 제목, 저장소, 폴더, 워크트리, 브랜치, 제공자, 컴퓨터, 최근 작업을 함께 찾는다.

## Consequences

- 같은 저장소의 세션도 브랜치, 워크트리, 최근 작업으로 구별해 고를 수 있다.
- 카드가 세 줄이라 `@` 목록이 한 화면에 보여 주는 세션 수가 줄어든다(최대 8개, 화면 높이에 맞춤).
- 최근 작업 한 줄은 요약 모델이 아니라 답의 첫 문장이라, 답이 결론부터 시작하지 않으면 덜 유용할 수 있다. 에이전트가 영어로 답한 세션은 영어로 보인다.
- 목록을 처음 불러올 때 세션 200개의 꼬리를 읽는다. 이후에는 바뀐 파일만 읽는다.
