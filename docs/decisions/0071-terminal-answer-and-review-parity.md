# 0071 — 터미널 답변·근거·복습 기능의 웹앱 parity

Date: 2026-10-15
Status: Accepted

## 문제

터미널은 세션과 대화를 고를 수 있었지만 웹앱의 답변 구조와 일부 학습 기능이 빠져 있었다. 답변의 세부 내용, 요청 모델과 설명 모드, 원문 근거, 배운 내용 다시보기, 용어 정리를 터미널에서 쓰려면 별도 흐름을 만들지 않고 같은 HTTP API와 공용 표시 규칙을 사용해야 한다.

## 결정

1. 세션을 고른 뒤 대화 선택창을 여는 현재 흐름을 유지한다. 대화 목록과 카드 제목·요약은 `app/conversations.mjs`를 웹과 터미널이 함께 사용한다.
2. 답변은 결론과 핵심 설명을 먼저 표시하고 `자세히 보기`는 접은 상태로 둔다. `/자세히`로 현재 답변의 `details`를 펼치거나 접는다.
3. 답변 아래에는 `answerMeta()`가 만든 설명 모드, 모드 출처, 요청 모델, 걸린 시간을 표시한다. 기본 모델은 답변에 기록된 세션 모델 출처를 그대로 보여 준다.
4. 답변에 저장된 인용이 있으면 `/근거`에서 인용을 검색해 고른다. `GET /api/evidence`의 현재 원문, 앞뒤 기록, 저장 발췌를 웹앱과 같은 구분으로 보여 준다.
5. `/복습 (review)`는 `GET /api/wiki`를 읽어 용어 선택창을 열고, 용어별 뜻과 관련 문답을 보여 준다. 정리되지 않은 과거 문답이 있으면 선택창의 고정 항목에서 `POST /api/wiki/extract`를 실행한다.
6. 모델 범위와 세션 모델 선택은 기존 프로필 API를 유지한다. 터미널 설정은 세션 모델 기본값과 프로필의 `modelScope`를 웹 설정과 같은 방식으로 사용한다.
7. 화면 선택은 검색어, 방향키, PgUp/PgDn, Enter, 마우스 휠·클릭·드래그를 같은 선택창 상태에 적용한다. 마우스 보고는 `/마우스`로 끌 수 있어 Herdr/터미널의 기본 글자 선택을 되돌릴 수 있다.

## 결과

- 웹과 터미널이 카드 제목·요약, 답변 메타데이터, 출처 라벨을 같은 함수로 계산한다.
- 터미널은 모델을 다시 호출하지 않고 저장된 답변·근거·용어 사전을 읽는다.
- 근거가 현재 원문과 연결되지 않으면 저장 발췌임을 구분해 보여 준다.
- 터미널의 전체 화면 제약 때문에 복습 검색과 근거 탐색은 선택창, 상세 내용과 원문은 대화 영역으로 표시한다.
