# 터미널과 웹의 기능 차이와 수정 계획

2026-10-15 조사. 웹앱(`app/index.html`, 서버 경로)과 터미널(`app/terminal-ui.mjs`)을 줄 단위로 비교했다. 결정 배경은 ADR 0068. 상태는 **같음**(웹과 같은 데이터와 규칙), **다름**(있지만 구조가 다름), **없음**, **이번에 고침**이다.

## 1. 세션 고르기

| 기능 | 웹 | 터미널 | 상태 | 계획 |
|---|---|---|---|---|
| 목록과 순서 | 서버 순서(Herdr에 열린 세션 먼저, 그다음 최근 활동 순, 최대 200개)를 그대로 10개씩 | 같은 순서, 선택창에서 스크롤 | 같음 | 더 보기 버튼은 필요 없음 |
| 검색 | 제목, 저장소, 폴더, 워크트리, 브랜치, 최근 작업, cwd, 첫 요청, host, Herdr 이름 | `@`와 Ctrl+P 선택창의 검색창 | 이번에 고침 | - |
| 세션 정보(폴더, 시작·마지막 시각, SSH 별칭, 처음 요청, `/api/transcript` 링크) | 팝업 | 고른 세션의 미리 보기 | 이번에 고침 | 전사 링크는 터미널 대상 아님 |
| 처음 고르는 세션 | 저장된 마지막 세션 | 지금 대화 중인 세션, 없으면 지금 폴더의 세션 | 이번에 고침 | - |
| host(다른 컴퓨터) 탭 | 탭 | 검색어에 host가 들어 있어 거를 수 있음 | 다름 | P3: 선택창 머리에 host 칩 |
| 세션 제목의 Nerd 아이콘 제거(ADR 0047) | 제거 | 제목 그대로 | 없음 | P3: `webTitle` 규칙을 공용으로 옮겨 터미널도 적용 |

## 2. 카드와 대화

| 기능 | 웹 | 터미널 | 상태 | 계획 |
|---|---|---|---|---|
| 카드 목록 순서 | 새것이 위, 세션 전체 대화는 따로 | 세션 전체 대화, 새 카드가 위, 저장 대화 | 이번에 고침 | - |

| `NEW`, 과거 기록 | 가장 새 비과거 카드 하나에 `NEW` | `NEW`, 시각 | 이번에 고침 | - |
| 미리 설명 상태 | 대기, 준비 중, 한도, 실패 | 준비 중, 대기, 한도. 실패 문구는 없음 | 이번에 고침(일부) | P2: 실패와 `GET /api/prefetch` 상태 |
| 카드 열기 | 오른쪽 대화창에 AI 출력(선택지 포함), 문답 | 대화 화면 맨 위에 같은 내용 | 다름(한 화면씩) | - |
| 세션을 열 때 | 카드나 대화를 열지 않음 | 대화 선택창을 이어서 열고 가장 새 카드를 미리 보임 | 다름(의도) | - |

| 고른 카드 미리 보기 | 없음(눌러야 열림) | 선택창 아래 | 터미널만 | - |

## 터미널에서 다루지 않음

PiP 창, 모바일 3화면 탐색, 패널 너비 조절, 글자 크기와 테마 선택은 화면 종류에 묶인 기능이다. `/api/learning`, `/api/sessions/resolve`는 HTTP 경로는 있지만 웹도 화면에서 쓰지 않는다.

## 순서

1. P1(다음 변경): 답 메타 줄과 세부 접기, `/근거`, `/대기` 선택창.
2. P2: 용어와 다시보기, 즐겨찾기 필터, 설정 확장(프로필 만들기, 분야별 깊이, 다른 기기), 실패 뒤 선택지, 미리 설명 상태.
3. P3: host 칩, 제목 아이콘 규칙, 빠른 설명 칩.

각 항목은 서버 변경 없이 기존 API와 공용 모듈(`conversations.mjs`, `session-client.mjs`, `transport.mjs`)에서 가져온다. 웹에만 있던 표시 규칙은 이번처럼 공용 모듈로 옮겨 웹과 터미널이 같은 함수를 쓴다.

## 확인이 남은 것

- 실제 한글 입력기와 터미널(Herdr 안의 Ghostty, Kaku 등)에서 조합 글자가 입력 위치에 뜨는지: 터미널과 입력기가 정하므로 이 저장소의 시험은 프레임에 쓴 커서 위치와 보임까지만 확인한다. 어긋나면 `DOCENT_HARDWARE_CURSOR=0`과 비교하고 터미널 이름과 함께 알려 달라.
